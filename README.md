# CodeAlpha Calculator

## Task 1: Basic Calculator Program

### Description

This project is a simple calculator program developed in C as part of the CodeAlpha C Programming Internship.

The program performs basic arithmetic operations using a switch-case statement.

### Features

- Addition
- Subtraction
- Multiplication
- Division
- Accepts integer and decimal numbers
- Handles division by zero
- Displays an error message for an invalid operator

### Concepts Used

- C Programming
- Variables
- float data type
- char data type
- printf() and scanf()
- switch-case
- if-else
- Arithmetic operators

### How the Program Works

1. The user enters the first number.
2. The user enters an arithmetic operator.
3. The user enters the second number.
4. The switch-case selects the required operation.
5. The result is displayed on the screen.
6. For division, the program checks whether the second number is zero.

### Supported Operators

| Operator | Operation |
|----------|-----------|
| +        | Addition |
| -        | Subtraction |
| *        | Multiplication |
| /        | Division |

### Sample Output

===== CALCULATOR =====
Enter first number: 10.5
Enter operator (+, -, *, /): +
Enter second number: 5
Result = 15.5
